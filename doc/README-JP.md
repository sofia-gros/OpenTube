# OpenTube

OpenTubeは、プライバシー、シンプルさ、そしてユーザーによるコントロールを重視したオープンソースのYouTubeクライアントです。

Googleアカウント不要。

トラッキングなし。

広告なし。

アルゴリズムによる視聴推奨なし。

OpenTubeを使えば、YouTubeコンテンツを閲覧・視聴しながら、登録チャンネル、視聴履歴、プレイリスト、設定などをすべて自分のデバイスに保存できます。

目標はシンプルです。

> データ管理を放棄することなく、YouTubeを視聴できること。

すべてのユーザーデータはローカルに保存されます。OpenTubeサーバーは存在しないため、何もサーバーにアップロードされません。

OpenTubeは、パフォーマンスを犠牲にすることなく、よりクリーンでカスタマイズ可能なYouTube体験を求めるユーザーのために設計されています。

今後のバージョンでは、YouTube Musicにも対応予定です。

## OpenTubeが存在する理由

現代のウェブプラットフォームは、ますます以下の要素に依存しています。

- ユーザー追跡
- パーソナライズされたプロファイリング
- 広告ネットワーク
- レコメンデーションの操作
- 必須のアカウント

OpenTubeは、これとは異なるアプローチを採用しています。

OpenTubeは、新たなソーシャルプラットフォームを構築するのではなく、ローカルファーストのクライアントとして機能し、ユーザーがコンテンツに直接アクセスできると同時に、自身のデータを管理できるようにします。

あなたの購読はあなたのものです。

あなたの視聴履歴はあなたのものです。

あなたのプレイリストはあなたのものです。

あなたの設定はあなたのものです。

クラウドサービスではありません。

広告会社ではありません。

アルゴリズムではありません。

## 理念

OpenTubeは、いくつかのシンプルな原則に基づいています。

### ローカルファースト

データはデバイス内に保存されます。

### アカウントは任意

動画を視聴するためだけにアカウントを作成する必要はありません。

### トラッキングなし

OpenTubeは、分析データやユーザー行動データを収集しません。

### 広告なし

コンテンツは広告によって隠されるべきではありません。


### ユーザー制御

アプリケーションの動作はユーザーが決定します。

アルゴリズムではありません。

## 開発

依存関係のインストール:

```bash
bun install
```

フロントエンドの起動:

```bash
bun run dev
```

バックエンドの起動:

```bash
bun run server
```

ビルド:

```bash
bun run build
```
